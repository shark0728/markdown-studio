# Markdown Studio v0.2.1

本次为自 v0.1.2 起的累积更新，包含 v0.2.0 的编辑效率功能与 v0.2.1 的边界修复；无需先安装 v0.2.0。

## Windows x64 下载

- `markdown-studio-0.2.1-x64-setup.exe`：NSIS 安装包，普通用户可选择此项。
- `markdown-studio-0.2.1-x64.msi`：MSI 安装包。
- `markdown-studio-0.2.1.exe`：独立运行文件，不需要开发服务器；仍需要 Windows WebView2。

升级前请手动保存文档并退出旧版。本软件尚未内置自动更新，需要自行下载并运行新版安装包；独立 EXE 不会自动替换原有桌面快捷方式。本次发布包未进行代码签名，Windows 可能提示未知发布者。

## 新功能

- Markdown 格式工具栏、选区/多光标格式化、撤销与重做。
- 最近文件筛选、打开、移除和清空记录（不删除磁盘文件）。
- 真正的仅编辑、左右分栏和仅预览模式。
- 搜索替换、行列/选区统计、自动换行和行号设置。
- 分栏拖拽、键盘调整、双击复位及偏好持久化。

## 修复

- 保存期间继续编辑时误标为已保存、并发文件操作和选择器异常处理。
- 未保存确认的焦点限制、后台快捷键隔离及弹窗内错误显示。
- 大纲/预览锚点、Setext/嵌套标题与长代码围栏解析。
- 空白、多段落选区格式失效，行内代码反引号/空格内容错误，大量反引号导致的异常。
- 换文档遗留旧预览滚动位置，以及启动期间默认偏好覆盖已有设置。

## 验证与边界

- 58 项单元/集成测试、9 项真实 CodeMirror 端到端测试、2 项 Rust 测试通过。
- lint、前端构建及 Windows EXE/MSI/NSIS 构建通过。
- 原生烟测验证文件切换、预览位置复位、取消关闭、UTF-8/CRLF 读写和保存后退出。
- 保持单文档、本地优先。未加入自动保存、正文恢复、云同步或多标签。
- 外部文件冲突检测、本地图片资源管理、超大文档性能优化仍待后续版本。当前仍有约 1.06 MB 主 JS 体积提示；安装包的覆盖安装流程尚未在本机执行。
